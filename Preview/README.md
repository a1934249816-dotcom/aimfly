# 本地交互预览

在 Windows 上解压完整文件夹后，用 Edge 或 Chrome 打开 `index.html`。`index.html`、`styles.css`、`core.js` 和 `app.js` 必须放在同一个文件夹中。无需安装依赖，也不需要联网。

这是用于检查界面和操作的浏览器预览，iPhone 原生 App 的源码位于上级文件夹。浏览器预览本身不是可以直接安装的 iOS 应用。

- 默认是简体中文、浅色、经典布局，首次打开没有预置联系人或通话记录。
- 点击右上角 `+` 添加通话；点击记录右侧的信息按钮查看详情并编辑。
- 可编辑姓名、号码、标签、日期、精确到秒的时间、时长、来电、去电、未接及已取消状态。未接或已取消记录的时长固定为零。
- 通讯录支持新建、编辑、删除和个人收藏。关联联系人改名后，记录显示更新后的姓名；历史电话号码保留。删除联系人也保留历史记录的姓名和号码。
- 拨号键盘、静音、扬声器、保留、通讯录、添加第二路通话、切换、合并和挂断均在应用内操作。挂断后保存本地记录。不会拨打、发送信息或访问系统电话记录。
- 在右上角过滤菜单内打开“设置与备份”，可切换布局和外观，导出或导入 JSON 备份。备份字段与原生版本对应，日期使用 ISO 8601 格式。

数据保存在当前浏览器的本地存储中。更换浏览器、移动文件地址、使用隐私模式、清理浏览器数据或更换设备可能无法继续访问原数据，请定期导出备份。保存失败时会显示错误，编辑内容会留在编辑页。导入备份需确认替换。

预览已在 Windows 的 Edge 中检查新增与编辑、刷新后保存、联系人的历史记录、收藏、搜索、存储失败、备份导入导出和双路通话；也检查了 320 × 568、375 × 667 和 390 × 844 的布局。尚未在真实 iPhone 的 Safari 上验证。
